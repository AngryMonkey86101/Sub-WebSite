# Команды управления «Табор VPN»

Шпаргалка: какие команды есть, что делает каждая и где её запускать. Подробности — в
[dispatcher/README.md](dispatcher/README.md), [server/README.md](server/README.md) и
[docs/RUNBOOK.md](docs/RUNBOOK.md).

## Где что работает

| Где | Что там | Как попасть |
|---|---|---|
| **VPS в РФ** | Диспетчер: следит за сервером из РФ, забирает бэкапы, заказывает серверы, переезжает | SSH под `root`, папка `~/sub-website/dispatcher` |
| **Сервер VPN за рубежом** | Портал, бот Telegram, AmneziaWG, Caddy | SSH под `deploy`, папка `~/family-vpn` (скрипты — под `root`) |
| **Telegram** | Бот: команды админа и покупателей | Чат с ботом |
| **Любой Linux или Windows** | Расшифровка бэкапа вашим ключом age | — |

## 1. Диспетчер — VPS в РФ (под root)

### Меню — главный способ управления

```bash
bash ~/sub-website/dispatcher/menu.sh
```

Пункты выбираются цифрами, `0` — назад или выход.

| Пункт | Что делает |
|---|---|
| 1 | Состояние сервера: доступен ли из РФ, последний бэкап, портал, серверы и балансы, аварийный переезд |
| 2 | Время до плановой смены сервера |
| 3 | Пинг до сервера за рубежом (ICMP и HTTPS) |
| 4 | Цены на тарифы у всех хостеров; затем 1 — какие тарифы можно заказать прямо сейчас |
| 5 | Выбранный тариф |
| 6 | Изменить тариф: хостер → дата-центр → тариф (с проверкой «✓ можно заказать») |
| 7 | Переезд сейчас: по очереди хостеров или у одного. Идёт переезд — смотреть ход, отменить ожидание сборки |
| 8 | Время плановой смены (по Москве) |
| 9 | Период плановой смены (дни) |
| 10 | Хостеры: основной и запасной, ключ API Aeza, разведка Aeza, **пробный заказ**, отмена пробного заказа, режим Aeza |
| 11 | Удаление серверов: поставить в очередь — удалится, как только хостер позволит |
| 12 | Плановая смена: включить или выключить |
| 13 | Аварийный переезд: включить, выключить, через сколько минут недоступности |

### Обновить диспетчер после изменений в main

```bash
git -C ~/sub-website pull && cd ~/sub-website/dispatcher && docker compose up -d --build
```

Ключи, бэкапы и состояние — в томе `dispatcher_data`, при обновлении не теряются.

### Команды диспетчера

Запускаются из папки диспетчера:

```bash
cd ~/sub-website/dispatcher
```

Общий вид — `docker compose exec dispatcher node src/cli.js КОМАНДА`. Например:

```bash
docker compose exec dispatcher node src/cli.js status
```

Где нужен один хостер — `--provider zomro` или `--provider aeza`, иначе берётся основной.

**Сервер и бэкапы**

| Команда | Что делает |
|---|---|
| `status` | Доступность сервера из РФ, последний бэкап, аварийный переезд |
| `check` | Проверить сервер из РФ сейчас |
| `backup` | Забрать бэкап с сервера сейчас |
| `server` | Состояние портала на сервере: `active` или `frozen` |
| `trust-host` | Забыть ключ SSH сервера — после ручного переезда на новый сервер |
| `keys` | Открытые ключи диспетчера — что вписать в `.env` сервера VPN |
| `freeze --yes` | Заморозить портал (бот, оплаты, сайт стоп; VPN работает) |
| `unfreeze` | Разморозить портал |

**Хостеры, тарифы, серверы**

| Команда | Что делает |
|---|---|
| `providers` | Хостеры: настроен ли, место в очереди, режим (auto / по запросу) |
| `servers` | Серверы у всех хостеров и балансы |
| `tariffs` | Тарифы и цены за день во всех дата-центрах |
| `tariff` | Выбранный тариф |
| `available [ДАТАЦЕНТР]` | Какие тарифы можно заказать прямо сейчас (только чтение, около минуты) |
| `tariff-check ТАРИФ ДАТАЦЕНТР` | Можно ли заказать тариф и какой образ ОС взять |
| `order-form ТАРИФ ДАТАЦЕНТР` | Форма заказа Zomro как есть — для разбора, если не находится образ ОС |
| `aeza-probe` | Разведка API Aeza (только чтение) |
| `delete-queue` | Очередь на удаление; `delete-queue add zomro НОМЕР` — добавить, `drop` — убрать |
| `remove НОМЕР --yes` | Удалить свой сервер (`family-vpn-…`) сразу; чужой — только с `--foreign` |
| `root-password [ИМЯ]` | Пароль root сервера, созданного диспетчером |

**Переезд**

| Команда | Что делает |
|---|---|
| `schedule` | Расписание плановой смены |
| `migrate --yes [--provider ИМЯ]` | Переехать сейчас. Долго — запускайте из меню (пункт 7), там он идёт в фоне |
| `migrate-status` | Как идёт или чем закончился последний переезд |
| `cancel-wait` | Отменить ожидание сборки: заказать у следующего хостера; `--all` — отменить переезд совсем |
| `cloud-test --yes [--provider ИМЯ]` | Пробный заказ: заказать сервер, войти по паролю, удалить (несколько центов). Удобнее — меню, 10 → 4 |

### Журналы

Ход переезда (в том числе аварийного):

```bash
docker compose exec dispatcher tail -n 40 -F /data/migrate.log
```

Пробный заказ:

```bash
docker compose exec dispatcher tail -n 40 /data/cloud-test.log
```

Журнал службы диспетчера:

```bash
docker compose logs --tail 100 dispatcher
```

### Настройки — файл `~/sub-website/dispatcher/.env`

Почти всё меняется из меню. Вручную — отредактировать файл и перезапустить: `docker compose up -d`.

| Переменная | Что задаёт |
|---|---|
| `ZOMRO_PRICELIST`, `ZOMRO_DATACENTER`, `ZOMRO_OS` | Тариф, дата-центр и образ ОС Zomro (меню, 6) |
| `AEZA_API_KEY`, `AEZA_PRODUCT` | Ключ и тариф Aeza (меню, 10 и 6) |
| `CLOUD_ORDER` | Очередь хостеров, например `zomro,aeza` |
| `ZOMRO_MODE`, `AEZA_MODE` | `auto` — участвует в автоматических переездах, `manual` — только по команде |
| `ROTATION_ENABLED`, `ROTATION_DAYS`, `ROTATION_TIME` | Плановая смена: вкл/выкл, период, время по Москве |
| `EMERGENCY_ENABLED`, `EMERGENCY_AFTER_MIN`, `EMERGENCY_RETRY_H` | Аварийный переезд: вкл/выкл (по умолчанию вкл), через сколько минут (30), повтор через (6 ч) |
| `ZOMRO_BUILD_MIN` | Сколько ждать сборку сервера Zomro (90 мин) |

## 2. Сервер VPN — за рубежом

### Под `deploy`, в папке портала

```bash
cd ~/family-vpn
```

| Команда | Что делает |
|---|---|
| `docker compose ps` | Что запущено |
| `docker compose up -d --build` | Пересобрать и запустить портал (обычно делает выкладка из GitHub) |
| `docker compose logs --tail 100 portal` | Журнал портала и бота |
| `docker compose exec portal npm run -s cli -- КОМАНДА` | Команды портала (ниже) |

**Команды портала** — подставляются вместо `КОМАНДА`:

| Команда | Что делает |
|---|---|
| `check [--keys]` | Имена DuckDNS, бот, связь с AmneziaWG; с `--keys` — пробный ключ |
| `invite [--admin] [--devices N]` | Новый участник и приглашение на 3 дня |
| `relink КОД` | Новое приглашение взамен потерянной ссылки |
| `list` | Участники и их устройства |
| `duckdns [--takeover]` | Проверить DuckDNS; с `--takeover` — направить имена на этот сервер |
| `backup` | Бэкап сейчас — в Telegram |

Пример:

```bash
docker compose exec portal npm run -s cli -- check --keys
```

### Под `root`

| Команда | Что делает |
|---|---|
| `bash /home/deploy/family-vpn/scripts/install-reboot.sh` | Включить перезагрузку из бота и админки (`--remove` — выключить) |
| `bash /home/deploy/family-vpn/scripts/install-dispatcher-key.sh` | Прописать ключ SSH диспетчера (после обновления портала или смены ключей) |
| `bash ~/sub-website/server/scripts/restore.sh БЭКАП.tar.gz.age` | Ручной переезд на новый сервер из бэкапа (на новом сервере). Диспетчер делает это сам |

Обновлять сервер вручную не нужно: пуш в `main` с изменениями в `server/` выкладывается сам (GitHub Actions).

## 3. Бот Telegram

**Админ** (в чате, привязанном в админке портала):

| Команда | Что делает |
|---|---|
| `/status` | Сервер VPN, ключи и IP |
| `/members` | Участники |
| `/invite` | Приглашение новому участнику |
| `/relink КОД` | Новая ссылка участнику |
| `/backup` | Бэкап сейчас |
| `/reboot`, затем `/reboot_confirm` | Перезагрузить сервер (VPN пропадёт на 1–2 минуты) |
| `/shop` | Продажи: состояние, места, выручка |
| `/orders` | Заказы, ждущие оплаты |
| `/grant НОМЕР` | Отметить заказ оплаченным |
| `/gift КОД ДНИ` | Добавить дни покупателю |
| `/refund НОМЕР [СУММА]` | Вернуть деньги |
| `/sales [ДНЕЙ]` | Отчёт о продажах |
| `/client` | Меню, которое видят покупатели |
| `/help` | Что умеет бот |

**Покупатели:** `/start` — меню, `/buy` — купить или продлить, `/keys` — мой доступ и ключи, `/help` — как подключиться.

## 4. Бэкап — на своём компьютере

Расшифровать бэкап из Telegram (нужен ваш закрытый ключ age из менеджера паролей):

```bash
age -d -i backup-key.txt family-vpn-ГГГГ-ММ-ДД.tar.gz.age | tar xz
```

Подробно, в том числе для Windows, — server/README.md, раздел «Восстановление из бэкапа».

## 5. Частые ситуации

| Ситуация | Что делать |
|---|---|
| Пришло «🔴 Из РФ сервер недоступен» | Ничего: через 30 минут диспетчер переедет сам («🚨 … аварийный переезд»). Переехать сразу — меню, 7 |
| Пришло «✅ Переезд закончен» | Семье: выключить и включить VPN |
| Переезд идёт, сервер долго собирается | Меню, 7 → отменить ожидание (следующий хостер) или отменить переезд |
| Проверить, что заказ у хостера работает | Меню, 10 → 4 (пробный заказ, несколько центов) |
| Тариф не заказывается | Меню, 4 → 1 или 6: выбрать тариф с «✓» |
| Лишний сервер у хостера стоит денег | Меню, 11 → поставить в очередь на удаление |
| Сообщения из РФ не приходят в Telegram | Нормально: идут через сервер VPN или ждут в очереди с пометкой «⏱ задержано» |
| Сервер завис и не отвечает на `/reboot` | Перезагрузить в личном кабинете хостера |
